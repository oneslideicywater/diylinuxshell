# 文档规则与路径规范

> 详细规则见 [doc-rules skill](../skills/doc-rules/SKILL.md)

## 文档类型速查

| 文档名 | 位置 | 职责 |
|--------|------|------|
| `digest.md` | 代码目录旁 | **函数摘要**：文件名、导出函数签名、一句话说明 |
| `code.md` | 代码目录旁 | **代码分析**：核心逻辑、设计决策、实现细节 |
| `arch.md` | 代码目录旁 | **架构设计**：模块关系图、分层原则、数据流 |
| `function-test.md` | `docs/relation/<功能>/` | **功能 ↔ 测试用例**对应关系 |
| `bug-test.md` | `docs/relation/<功能>/` | **bug ↔ 测试用例** + **bug ↔ 所属功能**映射 |

## 核心规范（精简版）

1. **避免重复**：已有详细内容的文档，其他处只写链接
2. **digest.md 只写函数清单**：不写大段设计说明、统计数字
3. **增删函数后必须更新 digest.md**
4. **每个文档职责清晰**：先检查是否已有覆盖，有则链接无则撰写
5. **Markdown 链接路径必须可 IDE 跳转**：使用正确的相对路径层级
