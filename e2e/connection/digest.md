# Connection 测试用例摘要

## 测试职责

测试 SSH 连接建立、连接错误处理、会话表单中的测试连接功能。

## 测试文件清单

| 文件 | 描述 |
|------|------|
| [connection.e2e.spec.ts](./connection.e2e.spec.ts) | 会话创建/编辑/删除、连接按钮、双击连接、标签页创建、连接状态显示、表单验证 |
| [connection-error.e2e.spec.ts](./connection-error.e2e.spec.ts) | 连接失败错误对话框、重新输入密码、编辑会话、修改密码后重连、标签页右键重连失败 |
| [test-connection.e2e.spec.ts](./test-connection.e2e.spec.ts) | 表单内测试连接按钮、空字段验证、连接成功/失败状态、加载状态显示 |

## 测试覆盖范围

- 会话表单创建和保存
- 连接按钮点击创建标签页
- 双击会话创建连接
- 多次连接创建多个独立标签页
- 连接失败错误对话框（关闭/重新输入密码/编辑会话）
- 标签页右键菜单重连失败处理
- 表单内测试连接功能
- 端口号范围验证
- 主机地址必填验证
