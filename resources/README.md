# Resources Directory

This directory contains application resources such as icons and other assets.

## Icon Requirements

### Windows
- `icons/icon.ico`: Application icon (256x256 recommended)

### Linux
- `icons/icon.png`: Application icon (512x512 recommended)
- `icons/icon.svg`: Vector icon (optional)

### macOS
- `icons/icon.icns`: Application icon (512x512 recommended)

### System Tray
- `icons/tray.png`: System tray icon (16x16 or 32x32)

## Creating Icons

You can use tools like:
- [electron-icon-builder](https://github.com/safu9/electron-icon-builder)
- [png-to-ico](https://github.com/steambap/png-to-ico)
- [icns-generator](https://github.com/alexander-heim/icns-generator)

Place your source icon (1024x1024 PNG recommended) and run the conversion tools.
