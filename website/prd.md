## 二、项目概述

### 2.1 项目背景

DIY-Linux-Shell 是一款基于 Electron + Vue 3 + TypeScript 构建的现代化 SSH 终端管理工具。产品已开发完成核心功能（多会话管理、SFTP 文件传输、终端分屏等），需要一个官方产品介绍网站来：

- 展示产品功能和特性
- 提供下载入口（链接到 GitHub Releases）
- 建立品牌形象
- 降低用户获取门槛

### 2.2 项目目标

**业务目标**：
- 为 DIY-Linux-Shell 建立专业的产品展示门户
- 提升产品知名度和用户转化率
- 作为产品对外宣传的统一入口

**产品目标**：
- 响应式设计，适配桌面端和移动端
- 快速加载，优化 SEO
- 支持 Vercel 一键部署
- 支持中英文双语（可选）

### 2.3 目标用户

**核心用户**：
- Linux 系统管理员
- 后端开发工程师
- DevOps 工程师
- 运维技术人员

**用户场景**：
- 通过搜索引擎了解 SSH 终端工具
- 在 GitHub 上发现项目后想了解更多
- 需要评估是否采用该工具

### 2.4 技术约束

- **部署平台**：Vercel
- **构建工具**：静态站点生成（SSG）或 SPA
- **技术栈**：推荐 Next.js / Nuxt / Vite + Vue/React
- **语言**：TypeScript
- **样式方案**：Tailwind CSS 或 UnoCSS

### 5.3 字体方案

采用 **Developer Mono** 组合（专为开发者工具优化）：

| 用途 | 字体 | 字重 | 说明 |
|------|------|------|------|
| 品牌/标题 | **JetBrains Mono** | 600-700 | 等宽字体做标题极具辨识度，与终端工具基因契合 |
| 正文/UI 文字 | **IBM Plex Sans** | 300-400-500-600 | 屏幕阅读优化，与 JetBrains Mono 同源协调 |
| 代码片段/命令 | **JetBrains Mono** | 400-500 | SSH 命令、配置示例展示 |

```css
/* Tailwind fontFamily 配置 */
fontFamily: {
  mono: ['"JetBrains Mono"', 'monospace'],       /* 代码 & 品牌标题 */
  sans: ['"IBM Plex Sans"', 'system-ui', 'sans-serif'], /* 正文内容 */
}
```

> Google Fonts 引用：`JetBrains Mono`(wght@400;500;600;700) + `IBM Plex Sans`(wght@300;400;500;600;700)

### 5.5 动效规范

| 效果 | 应用场景 | 参数 |
|------|----------|------|
| **滚动入场** | 各 Section 进入视口时 | `whileInView`, `staggerChildren: 0.1`, 方向: `y: 20 → 0` |
| **卡片 Hover** | Bento Grid 功能卡片 | `scale(1.02)`, `shadow-lg`, `border-color → primary`, `transition: 200ms` |
| **导航栏变化** | 页面滚动 > 50px 后 | `bg-white/80 backdrop-blur-xl border-b shadow-sm` |
| **按钮 Hover** | CTA / 链接按钮 | `background-color 加深`, `translate-y: -1px`, `200ms ease` |
| **图片入场** | ProductShowcase 截图 | `opacity: 0→1`, `y: 30→0`, `duration: 0.6s` |
