## 2. 产品概述

### 2.1 产品定位

DIY-Linux-Shell V1.3 在 V1.2 的基础上，增加命令片段管理功能，帮助用户快速执行常用命令，提升工作效率。

### 2.2 目标用户

- 后端开发工程师（需要频繁执行重复命令）
- Linux 系统管理员（需要定期执行维护命令）
- DevOps 工程师（需要标准化操作流程）

### 2.3 核心价值

| 价值点 | 说明 |
|--------|------|
| 快速执行 | 一键插入常用命令，减少重复输入 |
| 标准化管理 | 统一命令格式，降低操作风险 |
| 知识沉淀 | 积累常用命令，形成团队知识库 |
| 分类管理 | 按项目、场景组织命令片段 |

### 3.2 功能详情

#### 3.2.1 命令片段创建

**用户场景**：
- 用户发现某个命令需要频繁使用
- 用户希望保存常用命令以便后续快速使用

**功能描述**：
- 提供命令片段创建入口（工具栏按钮、右键菜单）
- 支持填写命令名称、命令内容、描述、分组、标签
- 支持命令语法高亮显示
- 支持实时预览

**验收标准**：
- [ ] 创建入口明显易用
- [ ] 必填字段验证（名称、命令内容）
- [ ] 命令内容支持多行
- [ ] 分组选择支持树形结构
- [ ] 标签支持输入和选择

#### 3.2.2 命令片段编辑

**用户场景**：
- 命令内容需要更新
- 命令描述需要补充

**功能描述**：
- 支持双击或右键菜单编辑命令片段
- 编辑界面与创建界面一致
- 支持版本历史（可选）

**验收标准**：
- [ ] 编辑操作便捷
- [ ] 修改后自动保存
- [ ] 支持撤销操作

#### 3.2.3 命令片段删除

**用户场景**：
- 命令片段不再使用
- 清理无效命令

**功能描述**：
- 支持右键菜单删除
- 删除前二次确认
- 支持批量删除

**验收标准**：
- [ ] 删除前有明确提示
- [ ] 支持撤销删除（可选）
- [ ] 批量删除操作便捷

#### 3.2.4 命令片段分组

**用户场景**：
- 命令片段数量较多，需要分类管理
- 按项目、场景组织命令

**功能描述**：
- 支持创建、编辑、删除分组
- 支持树形分组结构
- 支持拖拽移动命令片段到分组
- 分组支持图标选择

**验收标准**：
- [ ] 分组管理操作便捷
- [ ] 树形结构清晰
- [ ] 拖拽操作流畅

#### 3.2.5 命令片段搜索

**用户场景**：
- 命令片段数量多，需要快速查找
- 根据关键词定位命令

**功能描述**：
- 支持按名称搜索
- 支持按标签过滤
- 支持按分组过滤
- 支持搜索结果高亮

**验收标准**：
- [ ] 搜索响应快速
- [ ] 支持模糊匹配
- [ ] 搜索结果排序合理

#### 3.2.6 命令片段标签

**用户场景**：
- 命令片段属于多个分类
- 使用标签进行多维度标记

**功能描述**：
- 支持添加多个标签
- 支持标签输入和选择
- 支持按标签过滤

**验收标准**：
- [ ] 标签管理便捷
- [ ] 标签选择支持自动补全
- [ ] 标签过滤操作直观

#### 3.2.7 快速插入命令

**用户场景**：
- 在终端中快速执行保存的命令
- 减少手动输入

**功能描述**：
- 终端组件侧边栏显示命令片段面板
- 支持双击插入命令到终端
- 支持拖拽插入命令到终端
- 插入后光标自动定位到可编辑位置

**验收标准**：
- [ ] 插入操作流畅
- [ ] 命令内容完整
- [ ] 光标位置合理

#### 3.2.8 命令预览

**用户场景**：
- 插入前确认命令内容
- 避免误操作

**功能描述**：
- 鼠标悬停显示命令预览
- 预览显示完整命令内容
- 危险命令有特殊提示

**验收标准**：
- [ ] 预览显示清晰
- [ ] 响应快速
- [ ] 危险命令有明显标识

#### 3.2.9 执行确认

**用户场景**：
- 执行危险命令（如 rm -rf、dd 等）
- 避免误操作造成损失

**功能描述**：
- 识别危险命令关键词
- 执行前弹出确认对话框
- 显示危险等级和可能后果

**验收标准**：
- [ ] 危险命令识别准确
- [ ] 确认对话框信息完整
- [ ] 支持跳过确认（可选）

## 4. 非功能需求

### 4.1 性能需求

- 搜索响应时间 < 200ms
- 插入命令延迟 < 50ms
- 支持 1000+ 命令片段流畅使用

### 4.2 安全需求

- 危险命令识别准确率 > 95%
- 命令执行前必须有确认机制
- 无命令注入风险

### 4.3 可用性需求

- 界面简洁直观
- 操作流程不超过 3 步
- 支持快捷键操作

### 4.4 兼容性需求

- 支持深色/浅色主题
- 与其他功能无冲突

## 5. 数据模型

### 5.1 CommandSnippet

```typescript
interface CommandSnippet {
  id: string              // 唯一标识
  name: string            // 命令名称
  description?: string    // 命令描述
  command: string         // 命令内容
  groupId?: string        // 所属分组 ID
  tags?: string[]         // 标签列表
  createdAt: number       // 创建时间
  updatedAt: number       // 更新时间
}
```

### 5.2 CommandSnippetGroup

```typescript
interface CommandSnippetGroup {
  id: string              // 唯一标识
  name: string            // 分组名称
  icon?: string           // 分组图标
  order: number           // 排序顺序
  createdAt: number       // 创建时间
  updatedAt: number       // 更新时间
}
```

## 6. 原型设计

### 6.1 命令片段管理界面

```
┌─────────────────────────────────────────────────┐
│  命令片段管理                          [+ 新建] │
├─────────────────────────────────────────────────┤
│  [搜索框]  [分组筛选▼]  [标签筛选▼]            │
├──────────────┬──────────────────────────────────┤
│  分组树      │  命令片段列表                    │
│  ├─ 全部     │  ┌────────────────────────────┐ │
│  ├─ 常用命令 │  │  deploy.sh                 │ │
│  ├─ 系统维护 │  │  部署脚本...               │ │
│  └─ 项目 A   │  │  #tags: 部署 生产          │ │
│              │  └────────────────────────────┘ │
│              │  ┌────────────────────────────┐ │
│              │  │  backup-db                 │ │
│              │  │  数据库备份                │ │
│              │  │  #tags: 备份 数据库        │ │
│              │  └────────────────────────────┘ │
└──────────────┴──────────────────────────────────┘
```
