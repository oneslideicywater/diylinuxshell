## 2. 产品概述

### 2.1 产品定位

DIY-Linux-Shell V1.1 在 V1.0 MVP 的基础上，增加会话分组、命令片段等增强功能，提升用户的使用效率和体验。

### 2.2 目标用户

- Linux 系统管理员（需要管理大量服务器）
- 后端开发工程师（需要频繁执行重复命令）
- DevOps 工程师（需要在不同环境间切换）
- 需要高效管理多个会话的用户

### 2.3 核心价值

| 价值点 | 说明 |
|--------|------|
| 高效管理 | 会话分组功能，按项目/环境组织会话 |
| 快速操作 | 命令片段功能，快速执行常用命令 |
| 个性化 | 主题配置完善，满足个性化需求 |
| 安全认证 | 密钥认证支持，提升安全性 |

### 3.2 功能详细说明

#### 3.2.1 密钥认证

**功能描述**

| 项目 | 内容 |
|------|------|
| 功能描述 | 支持使用 SSH 私钥文件进行身份认证 |
| 认证方式 | 密码认证、密钥认证（二选一） |
| 密钥格式 | 支持 OpenSSH 格式的私钥文件 |
| 密钥保护 | 支持带密码保护的私钥 |

**用户流程**

```
1. 用户创建或编辑会话
2. 选择"密钥认证"
3. 选择私钥文件路径
4. （可选）输入私钥密码
5. 保存会话配置
6. 连接时使用密钥进行认证
```

**输入字段**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 认证类型 | 单选 | 是 | 密码认证 / 密钥认证 |
| 私钥路径 | 文件路径 | 是（密钥认证时） | 私钥文件路径 |
| 私钥密码 | 密码 | 否 | 私钥的保护密码 |

**安全要求**

- 私钥路径和密码加密存储
- 私钥密码不在界面明文显示
- 连接时临时解密使用

#### 3.2.2 会话分组

**功能描述**

| 项目 | 内容 |
|------|------|
| 功能描述 | 按项目、环境或其他维度对会话进行分组管理 |
| 分组层级 | 支持嵌套分组（最多 5 级） |
| 默认分组 | 默认分组（会话的默认归属分组，应用启动时自动创建） |
| 分组数量 | 无限制 |

**分组属性**

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 分组名称 | 文本 | 是 | 分组的显示名称 |
| 分组图标 | 图标 | 否 | 分组的图标（可选） |
| 展开状态 | 布尔 | 否 | 分组展开/折叠状态 |
| 排序顺序 | 数字 | 是 | 分组在列表中的显示顺序 |
| 父分组 ID | 字符串 | 否 | 父分组的 ID（支持嵌套分组） |
| 层级深度 | 数字 | 是 | 当前分组的层级深度（根分组为 1，最多 5 级） |

**删除二次确认**

删除含有会话的分组时，弹出确认对话框：

- **提示文字**：该分组包含 {count} 个会话，删除分组将会话全部删除，确定继续？
- **按钮样式**：确认按钮采用红色警告样式，取消按钮为默认样式

   - 分组头部右键 → 显示"添加会话到此分组"、"编辑分组"、"删除分组"菜单
   - 会话项右键 → 显示完整的会话操作菜单，包含以下菜单项：

| 序号 | 菜单项 | 说明 | 优先级 |
|------|--------|------|--------|
| 1 | 新增会话 | 创建新的会话配置 | P1 |
| 2 | 连接 | 连接到当前会话 | P1 |
| 3 | 编辑 | 编辑当前会话配置 | P1 |
| 4 | 复制会话 | 复制当前会话 | P1 |
| 5 | 分隔线 | - | - |
| 6 | 移动到分组 | 将当前会话移动到指定分组（带子菜单） | P1 |
| 7 | 分隔线 | - | - |
| 8 | 删除 | 删除当前会话 | P1 |
| 9 | 分隔线 | - | - |
| 10 | 属性 | 查看和修改会话属性 | P1 |
| 11 | 分隔线 | - | - |
| 12 | 审查元素 | 打开开发者工具并审查当前元素（开发调试用） | P2 |

2. **菜单项高亮效果**：
   - 鼠标悬停在菜单项上时，菜单项有明显的高亮背景色
   - 高亮效果使用过渡动画，提升视觉体验
   - 危险操作（如删除）有特殊的高亮颜色
   - 子菜单（移动到分组）在父菜单项 hover 时同时高亮

3. **分组图标选项**：
   - 文件夹图标（默认）
   - 服务器图标
   - 云图标
   - 数据库图标
   - 代码图标
   - 星标图标

3. **拖拽交互**：
   - 拖拽会话项到分组头部：高亮显示目标分组
   - 拖拽会话项到分组内会话之间：显示插入位置指示线
   - 松开鼠标完成归组

4. **批量操作**：
   - 按住 Ctrl/Cmd 多选会话
   - 右键选择"移动到分组"
   - 选择目标分组后批量移动

**界面样式**

1. **树形面板展示**：
   - 左侧会话侧边栏采用树形结构
   - 分组为父节点，会话为子节点
   - **支持多级嵌套分组（最多 5 级层级）**
   - 树形结构支持折叠/展开，可精确控制每个节点的显示状态
   - 子分组相对父分组缩进显示，层级关系清晰

2. **轻量化设计**：
   - 分组头部轻量化，仅显示图标、名称和会话数
   - 展开/折叠图标使用简洁的箭头（▶ 展开，▼ 折叠）
   - 悬停效果明显但不突兀
   - 无冗余操作，所有功能通过右键菜单或拖拽实现

3. **视觉反馈**：
   - 拖拽时目标分组高亮显示
   - 选中会话背景色变化
   - 删除分组时二次确认弹窗
   - 子分组缩进显示，层级关系清晰
   - **嵌套层级达到上限时，目标分组显示禁用状态（灰色、不可拖入）**

     


4. **嵌套分组特性**：
   - 子分组相对于父分组缩进显示
   - 折叠父分组时，自动折叠所有子分组
   - 展开父分组时，保持子分组的折叠/展开状态
   - 支持在任意层级的分组上创建子分组（受 5 级限制）
   - 创建或拖拽超限时，弹出明确的错误提示对话框

5. **搜索和定位**：
   - 支持按分组名称搜索，高亮匹配项
   - 支持快速定位到指定分组
   - 搜索结果可限定在特定分组内


#### 3.2.3 测试连接功能

**功能描述**

| 项目 | 内容 |
|------|------|
| 功能描述 | 在会话创建或编辑表单中，提供测试连接按钮，验证 SSH 连接配置是否可用 |
| 使用场景 | 创建新会话时验证配置、编辑会话后验证修改、连接失败时排查问题 |
| 连接测试 | 使用当前表单填写的配置建立临时 SSH 连接 |
| 结果反馈 | 在表单上直接显示测试结果（成功/失败） |

**功能需求**

| 功能项 | 描述 | 优先级 |
|--------|------|--------|
| 测试连接按钮 | 在会话表单底部添加"测试连接"按钮 | P1 |
| 字段验证 | 点击测试连接时验证必填字段（主机地址、端口、用户名） | P1 |
| 认证验证 | 根据认证方式验证密码或密钥路径是否填写 | P1 |
| 连接测试 | 使用表单配置建立临时 SSH 连接 | P1 |
| 结果显示 | 在表单上显示测试结果（成功绿色/失败红色） | P1 |
| 结果关闭 | 用户可手动关闭测试结果提示 | P1 |
| 加载状态 | 连接过程中按钮显示加载动画和"连接中..."文字 | P1 |
| 自动断开 | 测试连接成功后自动断开连接，不保存会话 | P1 |

**输入字段验证**

| 认证方式 | 必填字段 | 验证规则 |
|----------|----------|----------|
| 密码认证 | 主机地址、端口、用户名、密码 | 全部必填 |
| 密钥认证 | 主机地址、端口、用户名、密钥路径 | 全部必填 |

**界面设计**

1. **按钮位置**：
   - 位于会话表单底部
   - 在"取消"按钮左侧
   - 蓝色主题样式，区别于保存按钮

2. **测试结果显示**：
   - 位置：表单底部，按钮上方
   - 成功样式：绿色背景 + 对勾图标
   - 失败样式：红色背景 + 感叹号图标
   - 显示内容：成功时显示"成功连接到 {host}:{port}"，失败时显示具体错误信息
   - 关闭按钮：右上角提供关闭按钮

3. **加载状态**：
   - 按钮文字变为"连接中..."
   - 显示旋转 loading 图标
   - 按钮禁用，防止重复点击

**用户流程**

```
1. 用户创建或编辑会话
2. 填写会话配置信息
3. 点击"测试连接"按钮
4. 系统验证必填字段
5. 验证通过则发起 SSH 连接测试
6. 显示测试结果（成功/失败）
7. 用户查看结果后手动关闭
8. （可选）根据测试结果修改配置
```

**错误处理**

| 错误类型 | 提示文字 |
|----------|----------|
| 必填字段为空 | 请填写完整的主机地址、端口和用户名 |
| 密码为空（密码认证） | 密码认证需要输入密码 |
| 密钥路径为空（密钥认证） | 密钥认证需要选择密钥文件 |
| 连接超时 | 连接超时，请检查网络或主机地址 |
| 认证失败 | 认证失败，请检查用户名和密码/密钥 |
| 连接拒绝 | 连接被拒绝，请检查端口和防火墙设置 |
| 其他错误 | 连接失败，请稍后重试 |

**技术实现**

1. **前端验证**：
   - 在渲染进程验证必填字段
   - 验证不通过时直接显示错误，不发起连接

2. **IPC 通信**：
   - 新增 `session:test-connection` IPC 通道
   - 传递会话配置到主进程
   - 主进程返回连接结果（布尔值）

3. **主进程处理**：
   - 创建临时会话对象
   - 使用 SSHManager 建立连接
   - 连接成功后立即断开
   - 返回连接结果

4. **错误处理**：
   - 捕获 SSH 连接错误
   - 转换为用户友好的错误消息
   - 在界面上显示

**用户流程 - 删除分组**

```
1. 用户右键点击分组头部
2. 选择"删除分组"
3. 若分组包含会话，弹出二次确认
4. 确认删除
5. 分组删除，该分组下的会话移至"默认分组"
```

**界面要求**

- 分组可展开/折叠
- 展开状态记忆（刷新后保持）
- 分组显示会话数量
- 默认分组会话显示在最上方
- 所有分组操作有 Tooltip 提示

| 功能/元素 | Tooltip 文字 | 触发场景 |
|----------|-------------|----------|
| 新建分组 | 创建会话分组，归类管理远程主机连接 | 鼠标悬浮在新建分组按钮或菜单项上 |
| 拖拽会话 | 将会话拖入分组，实现快速整理 | 拖拽会话项时，悬浮在分组上 |
| 折叠/展开分组 | 点击折叠/展开分组，精简会话列表 | 鼠标悬浮在分组展开/折叠图标上 |
| 重命名分组 | 双击分组名称，可修改分组名 | 鼠标悬浮在分组名称上 |

### 7.2 会话分组实现

```typescript
// SessionStore 添加分组管理
const sessionGroups = ref<SessionGroup[]>([])

// 获取分组会话
function getGroupSessions(groupId: string): Session[] {
  return sessions.value.filter(s => s.groupId === groupId)
}

// 删除分组时移除会话关联
function removeSessionGroup(id: string): void {
  sessionGroups.value = sessionGroups.value.filter(g => g.id !== id)
  sessions.value.forEach(s => {
    if (s.groupId === id) {
      s.groupId = undefined
    }
  })
}
```
