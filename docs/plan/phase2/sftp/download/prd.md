## 2. 产品概述

### 2.1 功能定位

文件下载功能允许用户将远程 SFTP 服务器上的文件下载到本地文件系统，支持单文件下载和文件夹下载。

### 2.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 便捷下载 | 支持拖拽、右键菜单等多种下载方式 |
| 进度可视 | 实时显示下载进度，让用户掌握传输状态 |
| 批量下载 | 支持文件夹递归下载，提升效率 |
| 可中断 | 支持取消下载任务，灵活控制 |

### 3.2 功能详情

#### 3.2.1 单文件下载

**功能描述**：
- 支持将单个文件从远程服务器下载到本地
- 支持多种触发方式：拖拽、右键菜单
- 下载到当前本地目录
- **严禁弹出文件选择框**：下载操作必须基于远程目录栏中已选中的文件，不允许点击下载按钮后弹出文件选择对话框

**触发方式**：
1. **拖拽下载**：选中远程文件，拖拽到本地文件面板区域
2. **右键菜单下载**：右键点击右侧远程文件，弹出菜单选择"下载"

**用户场景**：
1. 用户在右侧远程文件面板选择一个文件
2. 通过以下方式触发下载：
   - 拖拽到左侧本地文件面板
   - 右键点击文件，选择"下载"选项
3. 系统开始下载文件，在树形进度中显示进度
4. 下载完成后，本地文件列表刷新

**验收标准**：
- [ ] 支持拖拽下载单个文件
- [ ] 支持右键菜单下载单个文件
- [ ] 下载进度在树形结构中实时显示（百分比、速度、剩余时间）
- [ ] 下载完成后自动刷新本地文件列表
- [ ] 下载失败时显示错误信息
- [ ] **严禁弹出文件选择对话框**：下载操作必须基于远程目录栏已选中的文件

#### 3.2.2 批量下载

**功能描述**：
- 支持选中多个文件同时下载
- 支持混合选择文件和文件夹下载
- 所有下载任务使用统一树形组件显示
- 批量任务在树形结构中按组显示
- **严禁弹出文件选择框**：下载操作必须基于远程目录栏中已选中的文件/文件夹，不允许弹出文件选择对话框

**触发方式**：
1. **多选下载**：按住 Ctrl/Cmd 选择多个文件，右键选择"下载"
2. **框选下载**：鼠标框选多个文件，拖拽到本地面板

**用户场景**：
1. 用户在右侧远程文件面板选择多个文件/文件夹
2. 右键点击选中项，选择"下载"选项
3. 系统创建批量下载任务，在统一树形结构中分组显示
4. 每个选中项作为独立节点或节点组显示
5. 批量任务完成后，本地文件列表刷新

**验收标准**：
- [ ] 支持 Ctrl/Cmd 多选文件下载
- [ ] 支持 Shift 连续多选文件下载
- [ ] 支持混合选择文件和文件夹下载
- [ ] 所有下载任务使用统一树形组件显示
- [ ] 批量任务在树形结构中清晰分组
- [ ] 支持取消批量任务中的单个任务
- [ ] 支持取消整个批量任务组
- [ ] 批量下载进度在树形结构中实时显示
- [ ] **严禁弹出文件选择对话框**：下载操作必须基于远程目录栏已选中的文件

#### 3.2.4 树形进度显示

**功能描述**：
- 使用树形结构实时显示当前下载任务的进度
- 文件夹作为父节点，文件和子文件夹作为子节点
- 支持展开/收起文件夹节点
- 显示下载速度、剩余时间、已传输大小
- 每个节点显示独立的进度状态
- **统一树形组件**：单文件、批量文件、文件夹下载均使用同一树形组件显示

**树形结构示例**：

**单文件下载：**
```
📄 file.txt (50% ⏳) │ /home/file.txt → D:\file.txt │ 1.2 MB/s │ 00:00:30 │ 00:00:25
```

**批量文件下载：**
```
📦 批量下载任务 (60%)
├── 📄 file1.txt (100% ✅)
├── 📄 file2.txt (50% ⏳)
└── 📄 file3.txt (30% ⏳)
```

**混合下载（文件 + 文件夹）：**
```
📦 批量下载任务 (45%)
├── 📄 file1.txt (100% ✅)
├── 📁 folder1 (25%)
│   ├── 📄 sub1.txt (50% ⏳)
│   └── 📄 sub2.txt (0% ⏸️)
└── 📄 file2.txt (10% ⏳)
```

**节点字段定义**：

| 字段名称 | 列宽 | 说明 | 示例 |
|----------|------|------|------|
| 名称 | 200px | 文件或文件夹名称，支持展开/收起图标 | 📁 文件夹 A |
| 状态 | 100px | 传输状态图标 | ⏳ 等待中、✅ 已完成、❌ 失败 |
| 进度 | 150px | 进度条 + 百分比 | ████████░░ 80% |
| 大小 | 120px | 文件大小（已传输/总大小） | 8.5 MB / 10.2 MB |
| 远程路径 | 自适应 | 远程文件完整路径 | /home/user/test.txt |
| ↔ | 40px | 方向箭头 | ← |
| 本地路径 | 自适应 | 本地完整路径 | D:\files\test.txt |
| 速度 | 100px | 当前传输速度 | 1.2 MB/s |
| 估计剩余 | 80px | 预计剩余时间 | 00:02:15 |
| 经过时间 | 80px | 已用时间 | 00:01:30 |

## 4. 用户体验要求

### 4.1 交互设计

- 拖拽下载时有视觉反馈（高亮目标区域）
- 下载过程中按钮状态禁用
- 取消按钮明显可见
- 进度条颜色符合主题

### 4.2 性能要求

- 单文件下载不阻塞 UI
- 文件夹下载时 UI 流畅
- 进度更新频率适中（不超过每秒 10 次）
- 大文件下载时内存占用合理

### 4.3 兼容性要求

- 支持 Windows、Linux、macOS
- 支持不同大小的文件（从几 KB 到几 GB）
- 支持各种文件类型
- 支持中文文件名

## 5. 数据埋点

| 事件 | 触发时机 | 埋点数据 |
|------|----------|----------|
| download_start | 开始下载 | 文件类型、文件大小、下载方式 |
| download_progress | 下载进度 | 已传输大小、总大小、速度 |
| download_complete | 下载完成 | 总耗时、平均速度、文件大小 |
| download_cancel | 取消下载 | 已完成进度、取消原因 |
| download_error | 下载失败 | 错误类型、错误信息、文件大小 |

---

## 6. 边界情况

| 场景 | 处理方式 |
|------|----------|
| 下载过程中断开连接 | 提示用户并重试 |
| 下载同名文件 | 提示覆盖或跳过 |
| 下载超大文件 | 正常下载，显示合适进度 |
| 下载 0 字节文件 | 正常下载 |
| 下载特殊字符文件名 | 转义处理后下载 |
| 下载过程中关闭程序 | 取消所有下载任务 |
| 本地磁盘空间不足 | 提前检查并提示 |
