## 2. 产品概述

### 2.1 功能定位

文件上传功能允许用户将本地文件系统中的文件上传到远程 SFTP 服务器，支持单文件上传和文件夹上传。

### 2.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 便捷上传 | 支持拖拽、右键菜单等多种上传方式 |
| 进度可视 | 实时显示上传进度，让用户掌握传输状态 |
| 批量上传 | 支持文件夹递归上传，提升效率 |
| 可中断 | 支持取消上传任务，灵活控制 |

### 3.2 功能详情

#### 3.2.1 单文件上传

**功能描述**：
- 支持将单个文件从本地上传到远程服务器
- 支持多种触发方式：拖拽、右键菜单
- 上传到当前远程目录
- **严禁弹出文件选择框**：上传操作必须基于本地目录栏中已选中的文件，不允许点击上传按钮后弹出文件选择对话框

**触发方式**：
1. **拖拽上传**：选中本地文件，拖拽到远程文件面板区域
2. **右键菜单上传**：右键点击左侧本地文件，弹出菜单选择"上传"

**用户场景**：
1. 用户在左侧本地文件面板选择一个文件
2. 通过以下方式触发上传：
   - 拖拽到右侧远程文件面板
   - 右键点击文件，选择"上传"选项
3. 系统开始上传文件，在树形进度中显示进度
4. 上传完成后，远程文件列表刷新

**验收标准**：
- [x] 支持拖拽上传单个文件
- [x] 支持右键菜单上传单个文件
- [x] 上传进度在树形结构中实时显示（百分比、速度、剩余时间）
- [x] 上传完成后自动刷新远程文件列表
- [x] 上传失败时显示错误信息
- [x] **严禁弹出文件选择对话框**：上传操作必须基于本地目录栏已选中的文件

#### 3.2.2 批量上传

**功能描述**：
- 支持选中多个文件同时上传
- 支持混合选择文件和文件夹上传
- 所有上传任务使用统一树形组件显示
- 批量任务在树形结构中按组显示
- **严禁弹出文件选择框**：上传操作必须基于本地目录栏中已选中的文件/文件夹，不允许弹出文件选择对话框

**触发方式**：
1. **多选上传**：按住 Ctrl/Cmd 选择多个文件，右键选择"上传"
2. **框选上传**：鼠标框选多个文件，拖拽到远程面板

**用户场景**：
1. 用户在左侧本地文件面板选择多个文件/文件夹
2. 右键点击选中项，选择"上传"选项
3. 系统创建批量上传任务，在统一树形结构中分组显示
4. 每个选中项作为独立节点或节点组显示
5. 批量任务完成后，远程文件列表刷新

**验收标准**：
- [x] 支持 Ctrl/Cmd 多选文件上传
- [x] 支持 Shift 连续多选文件上传
- [x] 支持混合选择文件和文件夹上传
- [x] 所有上传任务使用统一树形组件显示
- [x] 批量任务在树形结构中清晰分组
- [x] 支持取消批量任务中的单个任务
- [x] 支持取消整个批量任务组
- [x] 批量上传进度在树形结构中实时显示
- [x] **严禁弹出文件选择对话框**：上传操作必须基于本地目录栏已选中的文件

**用户场景**：

#### 3.2.4 树形进度显示

**功能描述**：
- 使用树形结构实时显示当前上传任务的进度
- 文件夹作为父节点，文件和子文件夹作为子节点
- 支持展开/收起文件夹节点
- 显示上传速度、剩余时间、已传输大小
- 每个节点显示独立的进度状态
- **统一树形组件**：单文件、批量文件、文件夹上传均使用同一树形组件显示

**树形结构示例**：

**单文件上传：**
```
📄 file.txt (50% ⏳) │ D:\file.txt → /home/file.txt │ 1.2 MB/s │ 00:00:30 │ 00:00:25
```

**批量文件上传：**
```
📦 批量上传任务 (60%)
├── 📄 file1.txt (100% ✅)
├── 📄 file2.txt (50% ⏳)
└── 📄 file3.txt (30% ⏳)
```

**混合上传（文件 + 文件夹）：**
```
📦 批量上传任务 (45%)
├── 📄 file1.txt (100% ✅)
├── 📁 folder1 (25%)
│   ├── 📄 sub1.txt (50% ⏳)
│   └── 📄 sub2.txt (0% ⏸️)
└── 📄 file2.txt (10% ⏳)
```

**节点字段定义**：

| 字段名称 | 列宽 | 说明 | 示例 |
|----------|------|------|------|
| 名称 | 200px | 文件或文件夹名称，支持展开/收起图标 | 📁 文件夹 A |
| 状态 | 100px | 传输状态图标 | ⏳ 等待中、✅ 已完成、❌ 失败 |
| 进度 | 150px | 进度条 + 百分比 | ████████░░ 80% |
| 大小 | 120px | 文件大小（已传输/总大小） | 8.5 MB / 10.2 MB |
| 本地路径 | 自适应 | 本地文件完整路径 | D:\files\test.txt |
| ↔ | 40px | 方向箭头 | → |
| 远程路径 | 自适应 | 远程服务器完整路径 | /home/user/test.txt |
| 速度 | 100px | 当前传输速度 | 1.2 MB/s |
| 估计剩余 | 80px | 预计剩余时间 | 00:02:15 |
| 经过时间 | 80px | 已用时间 | 00:01:30 |

## 4. 用户体验要求

### 4.1 交互设计

- 拖拽上传时有视觉反馈（高亮目标区域）
- 上传过程中按钮状态禁用
- 取消按钮明显可见
- 进度条颜色符合主题

### 4.2 性能要求

- 单文件上传不阻塞 UI
- 文件夹上传时 UI 流畅
- 进度更新频率适中（不超过每秒 10 次）
- 大文件上传时内存占用合理

### 4.3 兼容性要求

- 支持 Windows、Linux、macOS
- 支持不同大小的文件（从几 KB 到几 GB）
- 支持各种文件类型
- 支持中文文件名

## 5. 数据埋点

| 事件 | 触发时机 | 埋点数据 |
|------|----------|----------|
| upload_start | 开始上传 | 文件类型、文件大小、上传方式 |
| upload_progress | 上传进度 | 已传输大小、总大小、速度 |
| upload_complete | 上传完成 | 总耗时、平均速度、文件大小 |
| upload_cancel | 取消上传 | 已完成进度、取消原因 |
| upload_error | 上传失败 | 错误类型、错误信息、文件大小 |

---

## 6. 边界情况

| 场景 | 处理方式 |
|------|----------|
| 上传过程中断开连接 | 提示用户并重试 |
| 上传同名文件 | 提示覆盖或跳过 |
| 上传超大文件 | 正常上传，显示合适进度 |
| 上传 0 字节文件 | 正常上传 |
| 上传特殊字符文件名 | 转义处理后上传 |
| 上传过程中关闭程序 | 取消所有上传任务 |
