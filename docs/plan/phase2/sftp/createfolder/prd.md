## 2. 产品概述

### 2.1 功能定位

创建文件夹功能允许用户在本地文件系统和远程 SFTP 服务器上新建文件夹，仅支持通过右键菜单触发。

### 2.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 便捷创建 | 支持右键菜单创建方式 |
| 输入验证 | 智能验证文件夹名称，避免非法命名 |
| 即时刷新 | 创建成功后自动刷新文件列表 |
| 错误提示 | 清晰的错误信息反馈 |

### 3.2 功能详情

#### 3.2.1 本地创建文件夹

**功能描述**：
- 在本地文件面板中创建新文件夹
- 仅支持右键菜单触发方式
- 创建后自动刷新本地文件列表

**触发方式**：
1. **右键菜单创建**：在本地文件面板空白处右键，选择"新建文件夹"

**用户场景**：
1. 用户在本地文件面板空白处右键点击
2. 选择"新建文件夹"选项
3. 弹出输入框，提示输入文件夹名称
4. 用户输入文件夹名称并确认
5. 系统验证名称合法性
6. 在本地文件系统创建文件夹
7. 刷新本地文件列表，显示新文件夹

**验收标准**：
- [ ] 支持右键菜单创建文件夹
- [ ] 输入框默认名称为"新建文件夹"
- [ ] 自动选中默认名称，方便用户直接修改
- [ ] 验证文件夹名称（不能包含非法字符：\ / : * ? " < > |）
- [ ] 检测重名，提示"文件夹已存在"
- [ ] 创建成功后刷新文件列表
- [ ] 创建失败时显示错误信息

#### 3.2.2 远程创建文件夹

**功能描述**：
- 在远程 SFTP 服务器当前目录创建新文件夹
- 仅支持右键菜单触发方式
- 创建后自动刷新远程文件列表
- 支持创建多级文件夹（可选）

**触发方式**：
1. **右键菜单创建**：在远程文件面板空白处右键，选择"新建文件夹"

**用户场景**：
1. 用户在远程文件面板空白处右键点击
2. 选择"新建文件夹"选项
3. 弹出输入框，提示输入文件夹名称
4. 用户输入文件夹名称并确认
5. 系统验证名称合法性
6. 调用 SFTP 服务在远程服务器创建文件夹
7. 刷新远程文件列表，显示新文件夹

**验收标准**：
- [ ] 支持右键菜单创建文件夹
- [ ] 输入框默认名称为"新建文件夹"
- [ ] 自动选中默认名称，方便用户直接修改
- [ ] 验证文件夹名称（不能包含非法字符）
- [ ] 检测重名，提示"文件夹已存在"
- [ ] 创建成功后刷新远程文件列表
- [ ] 创建失败时显示错误信息（网络错误、权限错误等）
- [ ] 支持创建多级文件夹（如：folder1/folder2）

## 4. 交互设计

### 4.1 右键菜单

**本地文件面板右键菜单**：
```
新建文件夹
上传
刷新
```

**远程文件面板右键菜单**：
```
新建文件夹
下载
刷新
```

### 4.2 输入框设计

**弹窗样式**：
- 居中显示模态对话框
- 标题："新建文件夹"
- 输入框：默认值"新建文件夹"，自动选中
- 按钮："取消"、"确定"
- 支持 Enter 键确认，Esc 键取消

**输入验证**：
- 实时验证输入内容
- 非法字符显示红色警告
- 重名检测显示警告信息
- 确认按钮在输入为空或非法时禁用

### 4.3 错误提示

**错误类型**：
1. **名称为空**：提示"文件夹名称不能为空"
2. **非法字符**：提示"文件夹名称不能包含以下字符：\ / : * ? \" < > |"
3. **文件夹已存在**：提示"该名称的文件夹已存在"
4. **权限不足**：提示"没有权限在此位置创建文件夹"
5. **网络错误**：提示"网络连接失败，请检查网络"

## 5. 数据结构

### 5.1 文件夹创建请求

```typescript
interface CreateFolderRequest {
  /** 文件夹名称 */
  name: string
  /** 父路径 */
  parentPath: string
  /** 完整路径（parentPath + name） */
  fullPath: string
  /** 类型：local-本地，remote-远程 */
  type: 'local' | 'remote'
}
```

### 5.2 文件夹创建结果

```typescript
interface CreateFolderResult {
  /** 是否成功 */
  success: boolean
  /** 错误信息（失败时填写） */
  error?: string
  /** 创建的文件夹路径（成功时填写） */
  path?: string
}
```

## 7. 非功能需求

### 7.1 性能要求

- 输入验证响应时间 < 100ms
- 本地文件夹创建响应时间 < 500ms
- 远程文件夹创建响应时间 < 3s（依赖网络）

### 7.2 用户体验

- 输入框自动聚焦并选中默认文本
- 支持快捷键操作（Enter 确认，Esc 取消）
- 错误提示清晰易懂
- 创建成功后有明显的视觉反馈

### 7.3 安全性

- 严格验证文件夹名称，防止路径注入攻击
- 禁止创建包含 `..` 的文件夹名称
- 远程创建时验证会话有效性

---

## 8. 技术实现要点

### 8.1 本地文件夹创建

- 使用 Node.js `fs.mkdirSync` 或 `fs.promises.mkdir`
- 创建前检查文件夹是否存在
- 捕获并处理可能的异常（权限不足、磁盘满等）

### 8.2 远程文件夹创建

- 使用 SFTP 协议的 `mkdir` 命令
- 支持递归创建多级文件夹（可选）
- 处理网络超时和连接断开情况

### 8.3 输入验证

```typescript
// 非法字符检测
const illegalChars = /[\\/:*?"<>|]/
if (illegalChars.test(folderName)) {
  return { valid: false, error: '文件夹名称包含非法字符' }
}

// 重名检测
const exists = files.some(f => f.name === folderName && f.isDirectory)
if (exists) {
  return { valid: false, error: '文件夹已存在' }
}
```
