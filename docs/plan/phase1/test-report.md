## Bug 修复记录

### BUG-001: Tab 切换时终端不切换

**问题描述**: 点击切换 tab 页时，tab 页的样式是切换了，但是对应的终端内容没有切换。

**根因**: 原实现只创建了一个 XTerminal 组件实例，切换 tab 时只是改变了传入的 prop，终端实例不会真正切换。

**修复方案**: 为每个 tab 创建独立的终端实例，使用 `v-show` 控制显示。

**相关文档**: [BUG-001-tab-switch-terminal-not-switch.md](../../bugs/BUG-001-tab-switch-terminal-not-switch.md)

**修复状态**: ✅ 已修复

### BUG-002: 关闭标签页导致同会话标签页全部断开

**问题描述**: 点击关闭一个标签页时，其他属于同一会话的标签页全部断开连接。

**根因**: SSH连接是以会话ID为键存储的，一个会话ID对应一个SSH连接。关闭标签页时断开该会话ID的连接，导致所有使用该会话ID的标签页都断开。

**修复方案**: 为每个标签页创建独立的SSH连接，而不是共享会话的连接。

**相关文档**: [BUG-002-close-tab-disconnects-all.md](../../bugs/BUG-002-close-tab-disconnects-all.md)

**修复状态**: ✅ 已修复

## 测试最佳实践

1. **测试隔离**: 每个测试文件独立，不依赖其他测试的状态
2. **Mock 策略**: 外部依赖（如 SSH 连接）使用 Mock 对象
3. **测试命名**: 测试名称清晰描述测试场景
4. **断言明确**: 每个测试有明确的断言点
