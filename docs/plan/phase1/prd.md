## 2. 产品概述

### 2.1 产品定位

DIY-Linux-Shell V1.0 是一个最小可行产品（MVP），目标是实现核心 SSH 连接功能，让用户能够通过密码认证连接远程 Linux 服务器并进行终端操作。

### 2.2 目标用户

- Linux 系统管理员
- 后端开发工程师
- DevOps 工程师
- 需要远程管理服务器的技术人员

### 2.3 核心价值

| 价值点 | 说明 |
|--------|------|
| 简单易用 | 一键连接，无需复杂配置 |
| 安全可靠 | 密码加密存储，安全通信 |
| 多会话管理 | 支持多标签页，高效切换 |
| 兼容性好 | 支持 vi/vim 等终端应用 |

## 3. 功能需求

| 会话管理 | 删除会话 | P0 | 删除不需要的会话 |
| 会话管理 | 会话列表 | P0 | 显示所有会话配置（名称、主机、端口、用户名），不显示连接状态 |

| SSH 连接 | 连接状态 | P0 | 显示连接状态 |
| SSH 连接 | 断开连接 | P0 | 主动断开连接 |
| 终端 | 终端显示 | P0 | 显示服务器输出 |
| 终端 | 终端输入 | P0 | 发送用户输入 |
| 终端 | 终端大小调整 | P0 | 自适应窗口大小 |
| 标签页 | 创建标签页 | P0 | 打开新标签页 |
| 标签页 | 关闭标签页 | P0 | 关闭标签页 |
| 标签页 | 切换标签页 | P0 | 切换活动标签页 |
| 标签页 | 连接状态显示 | P0 | 标签页显示连接状态（已连接、连接中、断开、错误） |
| 标签页 | 右键菜单 | P0 | 右键点击标签页显示上下文菜单，包含复制会话、断开会话、重连会话等操作 |
| 标签页 | 复制会话 | P0 | 点击"复制会话"创建新标签页，使用相同的会话配置自动连接 |

### 3.2 功能详细说明

#### 3.2.1 会话管理

**创建会话**

| 项目 | 内容 |
|------|------|
| 功能描述 | 创建新的 SSH 会话配置 |
| 输入字段 | 名称、主机地址、端口、用户名、密码 |
| 验证规则 | 名称必填、主机地址必填、端口范围 1-65535、用户名必填、密码必填 |
| 输出 | 创建成功提示、会话列表更新 |

**编辑会话**

| 项目 | 内容 |
|------|------|
| 功能描述 | 修改已有会话配置 |
| 输入字段 | 名称、主机地址、端口、用户名、密码（密码可选修改） |
| 验证规则 | 同创建会话 |
| 输出 | 修改成功提示、会话列表更新 |

**删除会话**

| 项目 | 内容 |
|------|------|
| 功能描述 | 删除不需要的会话 |
| 操作 | 点击删除按钮 → 确认对话框 → 删除 |
| 输出 | 删除成功提示、会话列表更新 |

#### 3.2.2 SSH 连接

**密码认证连接**

| 项目 | 内容 |
|------|------|
| 功能描述 | 使用密码连接 SSH 服务器 |
| 前置条件 | 会话配置已保存 |
| 操作流程 | 双击会话 → 建立连接 → 显示终端 |
| 连接状态 | 连接中、已连接、断开、错误 |
| 错误处理 | 显示错误信息、支持重试 |

**断开连接**

| 项目 | 内容 |
|------|------|
| 功能描述 | 主动断开 SSH 连接 |
| 操作方式 | 关闭标签页、右键菜单断开 |
| 输出 | 连接状态更新为断开 |

#### 3.2.3 终端

**终端显示**

| 项目 | 内容 |
|------|------|
| 功能描述 | 显示服务器输出内容 |
| 技术实现 | xterm.js |
| 支持特性 | ANSI 颜色、光标控制、滚动 |
| 缓冲区 | 最多保留 10000 行 |

**终端输入**

| 项目 | 内容 |
|------|------|
| 功能描述 | 发送用户输入到服务器 |
| 支持按键 | 普通字符、功能键、组合键 |
| 特殊按键 | Ctrl+C、Ctrl+D、Tab 等 |

**终端大小调整**

| 项目 | 内容 |
|------|------|
| 功能描述 | 自适应窗口大小 |
| 触发时机 | 窗口大小改变、标签页切换 |
| 同步方式 | 通过 SSH 通道同步到服务器 |

#### 3.2.4 标签页

**标签页管理**

| 项目 | 内容 |
|------|------|
| 创建标签页 | 双击会话、右键菜单打开 |
| 关闭标签页 | 点击关闭按钮、右键菜单关闭 |
| 切换标签页 | 点击标签页、快捷键切换 |
| 标签页标题 | 显示会话名称或动态标题 |
| 连接状态 | 显示连接状态指示器（已连接🟢、连接中🟡、断开⚪、错误🔴） |

## 4. 非功能需求

### 4.1 性能需求

| 指标 | 要求 |
|------|------|
| 启动时间 | < 3 秒 |
| 连接时间 | < 5 秒（正常网络） |
| 终端响应 | < 100ms 延迟 |
| 内存占用 | < 200MB（空闲状态） |

### 4.2 安全需求

| 需求 | 说明 |
|------|------|
| 密码加密 | 使用 AES-256 加密存储 |
| 安全通信 | IPC 通信使用 contextBridge |
| 敏感信息 | 不在日志中记录密码 |

### 4.3 兼容性需求

| 需求 | 说明 |
|------|------|
| 操作系统 | Windows 10+、Linux |
| 终端应用 | 支持 vi/vim、top、htop 等 |
| 字符编码 | UTF-8 |

### 4.4 可用性需求

| 需求 | 说明 |
|------|------|
| 界面友好 | 简洁直观的操作界面 |
| 错误提示 | 清晰的错误信息 |
| 操作反馈 | 操作成功/失败提示 |

## 5. 用户故事

### 5.1 会话管理

**US-001: 创建会话**

```
作为一名 系统管理员
我想要 创建一个新的 SSH 会话配置
以便于 快速连接到我的服务器

验收标准:
- 可以输入会话名称、主机、端口、用户名、密码
- 所有必填字段有验证提示
- 创建成功后会话列表自动更新
- 密码加密存储
```

**US-002: 编辑会话**

```
作为一名 系统管理员
我想要 修改已有会话的配置
以便于 更新服务器信息

验收标准:
- 可以修改会话的所有配置项
- 密码字段显示为空，修改时才填写
- 修改成功后自动更新会话列表
```

**US-003: 删除会话**

```
作为一名 系统管理员
我想要 删除不需要的会话配置
以便于 保持会话列表整洁

验收标准:
- 删除前有确认对话框
- 删除成功后会话列表自动更新
- 如果会话已连接，先断开再删除
```

### 5.2 SSH 连接

**US-004: 连接服务器**

```
作为一名 系统管理员
我想要 通过密码认证连接到远程服务器
以便于 进行服务器管理

验收标准:
- 双击会话即可连接
- 显示连接状态（连接中、已连接、错误）
- 连接失败时显示错误信息
- 连接成功后显示终端界面
```

**US-005: 断开连接**

```
作为一名 系统管理员
我想要 主动断开 SSH 连接
以便于 结束会话

验收标准:
- 关闭标签页时自动断开连接
- 右键菜单可手动断开连接
- 断开后连接状态更新
```

### 5.3 终端操作

**US-006: 终端输入输出**

```
作为一名 系统管理员
我想要 在终端中输入命令并查看输出
以便于 执行服务器操作

验收标准:
- 键盘输入正确发送到服务器
- 服务器输出正确显示在终端
- 支持 ANSI 颜色显示
- 支持光标控制
```

**US-007: 使用 vi/vim**

```
作为一名 系统管理员
我想要 在终端中使用 vi/vim 编辑文件
以便于 修改服务器上的配置文件

验收标准:
- vi/vim 正常启动和退出
- 编辑模式正常工作
- 保存文件正常
- 无显示异常或卡顿
```

### 5.4 标签页管理

**US-008: 多标签页**

```
作为一名 系统管理员
我想要 同时打开多个终端标签页
以便于 同时管理多台服务器

验收标准:
- 可以打开多个标签页
- 可以切换标签页
- 可以关闭单个标签页
- 每个标签页独立运行
```

## 7. 数据模型

### 7.1 会话 (Session)

```typescript
interface Session {
  id: string                    // 唯一标识
  name: string                  // 会话名称
  host: string                  // 主机地址
  port: number                  // 端口号
  username: string              // 用户名
  password?: string             // 加密后的密码
  authType: 'password'          // 认证类型（V1.0 仅支持密码）
  status: ConnectionStatus      // 连接状态
  createdAt: Date               // 创建时间
  updatedAt: Date               // 更新时间
}

type ConnectionStatus = 
  | 'disconnected'              // 未连接
  | 'connecting'                // 连接中
  | 'connected'                 // 已连接
  | 'error'                     // 连接错误
```

### 7.2 标签页 (Tab)

```typescript
interface Tab {
  id: string                    // 唯一标识
  sessionId: string             // 关联的会话 ID
  title: string                 // 标签页标题
  status: ConnectionStatus      // 连接状态
  isActive: boolean             // 是否激活
}

type ConnectionStatus = 
  | 'disconnected'              // 未连接
  | 'connecting'                // 连接中
  | 'connected'                 // 已连接
  | 'error'                     // 连接错误
```
