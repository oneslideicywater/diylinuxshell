# SFTP 文件传输功能展示

## 功能概述

SFTP 文件传输功能提供类似 Xftp 的双面板文件管理界面，支持本地和远程服务器之间的文件传输。

## 界面预览

### 主界面

![SFTP 文件传输界面](./sftp-main-view.png)

**界面说明**：

- **左侧面板**：本地文件浏览器，显示本地文件系统
- **右侧面板**：远程文件浏览器，显示 SSH 服务器上的文件系统
- **顶部工具栏**：路径导航、刷新、新建文件夹等操作
- **底部状态栏**：传输任务列表和进度显示

### 主要功能

#### 1. 文件浏览
- 本地和远程文件并列显示
- 支持双击进入文件夹
- 支持路径输入框快速跳转

#### 2. 文件传输
- **上传**：本地文件 → 远程服务器
- **下载**：远程文件 → 本地
- 支持文件和文件夹的批量传输
- 拖拽式操作体验

#### 3. 进度管理
- 树形进度展示
- 实时显示每个文件的传输状态
- 支持取消传输任务

#### 4. 右键菜单
- 本地文件右键菜单
- 远程文件右键菜单
- 根据上下文显示不同操作选项

## 技术特性

- ✅ 双面板布局设计
- ✅ 本地/远程文件列表
- ✅ 文件上传/下载
- ✅ 文件夹递归上传/下载
- ✅ 新建文件夹
- ✅ 删除文件/文件夹
- ✅ 树形传输进度显示
- ✅ 取消传输机制
- ✅ 状态机保护（Task FSM + Node FSM）
- ✅ 分布式右键菜单管理
