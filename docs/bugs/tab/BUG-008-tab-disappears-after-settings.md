# BUG-008: 打开设置后返回主界面标签页内容消失

## 问题描述

**发现日期**: 2026-04-02

**严重程度**: 高

**影响范围**: 标签页管理 - 终端会话

**问题描述**: 
用户创建SSH连接并打开标签页后，进入设置页面，返回主界面时，标签页内容消失。这会导致用户丢失当前的工作状态，严重影响用户体验。

## 复现步骤

1. 启动应用程序
2. 创建一个新的SSH连接
3. 连接成功后，终端内容正常显示
4. 点击设置按钮进入设置页面
5. 点击返回按钮返回主界面
6. 观察标签页内容消失

## 预期行为

- 标签页应该保持显示
- 终端内容应该保持不变
- SSH连接应该保持连接状态
- 用户应该能够继续在标签页中工作

## 实际行为

- 标签页内容消失
- 可能的问题：
  - 标签页被意外关闭
  - 终端组件被销毁
  - 路由切换导致状态丢失
  - 组件重新渲染导致状态丢失

## 根本原因分析

**已确认**：路由切换时组件状态丢失

在 `App.vue` 中，`<router-view />` 没有使用 `<keep-alive>` 包裹，导致路由切换时组件被完全销毁。当从主页（Home.vue）切换到设置页面（Settings.vue），再返回主页时：

1. **组件销毁**：Home.vue 组件被销毁，AppLayout 组件也被销毁
2. **状态丢失**：AppLayout 中的所有状态（包括标签页、终端实例）全部丢失
3. **组件重建**：返回主页时，Home.vue 和 AppLayout 重新创建，状态重置为初始值

### 问题代码

```vue
<!-- App.vue - 修复前 -->
<template>
  <div class="app-container">
    <router-view />
  </div>
</template>
```

### 影响范围

- 标签页状态丢失
- 终端实例被销毁
- SSH 连接断开
- 用户工作状态丢失

## 影响的文件

- `src/renderer/src/App.vue` - 应用根组件（已修复）

## 解决方案

### 方案 1: 使用 keep-alive 保持组件状态（已采用）

在 `App.vue` 中使用 `<keep-alive>` 包裹 `<router-view>`，保持路由组件状态：

```vue
<!-- App.vue - 修复后 -->
<template>
  <div class="app-container">
    <!-- 修复 BUG-008: 使用 keep-alive 保持路由组件状态，防止标签页消失 -->
    <router-view v-slot="{ Component }">
      <keep-alive>
        <component :is="Component" />
      </keep-alive>
    </router-view>
  </div>
</template>
```

### keep-alive 工作原理

- **缓存组件实例**：keep-alive 会缓存不活动的组件实例，而不是销毁它们
- **保持状态**：组件的所有状态（data、computed、setup 中的响应式数据）都会被保留
- **生命周期变化**：
  - 组件不会被销毁（不会触发 `onUnmounted`）
  - 组件会被停用和激活（触发 `onDeactivated` 和 `onActivated`）

### 优点

- ✅ 简单有效，只需修改一处
- ✅ 自动保持所有路由组件的状态
- ✅ 提升用户体验，避免状态丢失
- ✅ 减少不必要的组件销毁和重建

### 注意事项

- keep-alive 会占用更多内存（缓存组件实例）
- 如果某些页面不需要缓存，可以使用路由 meta 配置动态控制
- 组件中可以使用 `onActivated` 和 `onDeactivated` 生命周期钩子
