# BUG-007 - 编辑会话时密码处理问题

## 复现步骤

1. 创建一个会话，填写所有信息并保存
2. 右键点击该会话，选择"编辑会话"
3. 发现密码输入框是空的，或者显示的是加密后的密码
4. 点击"测试连接"，因为密码为空，提示需要输入密码
5. 点击"取消"，表单关闭

## 原因

1. 在 `SessionForm.vue` 中，编辑会话时密码被初始化为空字符串
2. GET_ALL 和 GET_BY_ID 返回的是加密后的密码

## 第二次修复（最终修复）

**文件：** `src/main/ipc/session.ts:21-50`

### 问题

第一次修复后，显示的是加密后的密码，而不是解密后的密码。

### 解决方案

修改 GET_ALL 和 GET_BY_ID 处理器，在返回会话前解密密码。

### 更改前

```typescript
ipcMain.handle(IPC_CHANNELS.SESSION.GET_ALL, () => {
  return StoreService.getSessions()
})

ipcMain.handle(IPC_CHANNELS.SESSION.GET_BY_ID, (_event, id: string) => {
  return StoreService.getSessionById(id)
})
```

### 更改后

```typescript
ipcMain.handle(IPC_CHANNELS.SESSION.GET_ALL, () => {
  const sessions = StoreService.getSessions()
  // 解密所有会话的密码
  return sessions.map(session => {
    const decryptedSession = { ...session }
    if (decryptedSession.password) {
      decryptedSession.password = CryptoService.decrypt(decryptedSession.password)
    }
    if (decryptedSession.keyPassphrase) {
      decryptedSession.keyPassphrase = CryptoService.decrypt(decryptedSession.keyPassphrase)
    }
    return decryptedSession
  })
})

ipcMain.handle(IPC_CHANNELS.SESSION.GET_BY_ID, (_event, id: string) => {
  const session = StoreService.getSessionById(id)
  if (!session) return undefined
  // 解密密码
  const decryptedSession = { ...session }
  if (decryptedSession.password) {
    decryptedSession.password = CryptoService.decrypt(decryptedSession.password)
  }
  if (decryptedSession.keyPassphrase) {
    decryptedSession.keyPassphrase = CryptoService.decrypt(decryptedSession.keyPassphrase)
  }
  return decryptedSession
})
```

## 第三次修复（实际修复）

**文件：** `src/renderer/src/views/Home.vue:43-53,107-124`

### 问题

第二次修复后，bug 依然存在！因为 sessionStore 中存储的是旧的加密密码，而编辑会话时直接使用的是 sessionStore 中的旧会话数据！

### 解决方案

修改 Home.vue 中的 handleEditSession、handleRetryFromError、handleEditFromError，在编辑会话时，重新从后端获取会话，确保密码是解密后的！

### 更改前

```typescript
// handleEditSession
const handleEditSession = (session: Session) => {
  editingSession.value = session
  showSessionForm.value = true
}

// handleRetryFromError
const handleRetryFromError = (sessionId: string): void => {
  const session = sessionStore.sessions.find(s => s.id === sessionId)
  if (session) {
    handleEditSession(session)
  }
}

// handleEditFromError
const handleEditFromError = (sessionId: string): void => {
  const session = sessionStore.sessions.find(s => s.id === sessionId)
  if (session) {
    handleEditSession(session)
  }
}
```

### 更改后

```typescript
// handleEditSession
const handleEditSession = async (session: Session) => {
  // 重新从后端获取会话，确保密码是解密后的
  // 因为 sessionStore 中可能存储的是旧的加密密码
  const freshSession = await window.api.session.getById(session.id)
  if (freshSession) {
    editingSession.value = freshSession
  } else {
    editingSession.value = session
  }
  showSessionForm.value = true
}

// handleRetryFromError
const handleRetryFromError = async (sessionId: string): void => {
  // 重新从后端获取会话，确保密码是解密后的
  const freshSession = await window.api.session.getById(sessionId)
  if (freshSession) {
    handleEditSession(freshSession)
  }
}

// handleEditFromError

  // 重新从后端获取会话，确保密码是解密后的

```

## 解决方法

1. 在 `SessionForm.vue` 中，编辑会话时保留原密码（password、keyPassphrase）
2. 修改位置：`src/renderer/src/components/session/SessionForm.vue:411,413`
3. 修改 `GET_ALL` 和 `GET_BY_ID` 处理器，返回解密后的密码
4. 修改位置：`src/main/ipc/session.ts:21-50`
5. 修改 Home.vue 中的 handleEditSession 等函数，编辑会话时重新从后端获取会话
6. 修改位置：`src/renderer/src/views/Home.vue:43-53,107-124`

## 第四次修复（CREATE 和 UPDATE 返回解密后的密码）

**文件：** `src/main/ipc/session.ts:56-111`

### 问题

之前的修复中，CREATE 和 UPDATE 处理器返回的是加密密码！导致 sessionStore 中存储的是加密密码！

### 解决方案

修改 CREATE 和 UPDATE 处理器，返回解密后的密码！

### 更改前

```typescript
// CREATE
ipcMain.handle(IPC_CHANNELS.SESSION.CREATE, ...) {
  ...
  StoreService.addSession(session)
  return session
}

// UPDATE
ipcMain.handle(IPC_CHANNELS.SESSION.UPDATE, ...) {
  ...
  StoreService.updateSession(id, updates)
  return StoreService.getSessionById(id)
}
```

### 更改后

```typescript
// CREATE
ipcMain.handle(IPC_CHANNELS.SESSION.CREATE, ...) {
  ...
  StoreService.addSession(session)
  
  // 返回解密后的会话
  const decryptedSession = { ...session }
  if (decryptedSession.password) {
    decryptedSession.password = CryptoService.decrypt(decryptedSession.password)
  }
  if (decryptedSession.keyPassphrase) {
    decryptedSession.keyPassphrase = CryptoService.decrypt(decryptedSession.keyPassphrase)
  }
  return decryptedSession
}

// UPDATE
ipcMain.handle(IPC_CHANNELS.SESSION.UPDATE, ...) {
  ...
  StoreService.updateSession(id, updates)
  
  // 返回解密后的会话
  const session = StoreService.getSessionById(id)
  if (!session) return undefined
  
  const decryptedSession = { ...session }
  if (decryptedSession.password) {
    decryptedSession.password = CryptoService.decrypt(decryptedSession.password)
  }
  if (decryptedSession.keyPassphrase) {
    decryptedSession.keyPassphrase = CryptoService.decrypt(decryptedSession.keyPassphrase)
  }
  return decryptedSession
}
```
