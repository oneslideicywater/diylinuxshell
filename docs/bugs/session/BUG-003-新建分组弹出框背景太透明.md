# BUG-003: 新建分组弹出框背景太透明

## 问题描述

右键点击新建分组时，弹出的分组表单背景遮罩层完全透明，导致可以看到表单底层的内容，影响视觉效果。

## 问题原因

1. `SessionGroupForm.vue` 组件中的 `.group-form-overlay` 类的 `background` 属性设置为 `transparent`，没有遮罩效果
2. 表单 `.group-form` 使用了 `var(--bg-secondary)` 变量，该变量可能也是半透明的
3. 表单容器和装饰元素的 `opacity` 设置导致内容过于透明

## 复现步骤

1. 启动应用
2. 右击会话列表空白区域或分组
3. 选择"新建分组"菜单项
4. 观察弹出框的背景遮罩和表单透明度

**预期结果**: 背景应该有半透明遮罩，表单应该不透明（opacity: 1），遮挡底层内容
**实际结果**: 背景完全透明，表单也可能透明，可以看到底层内容

## 修复方案

修改 `src/renderer/src/components/session/SessionGroupForm.vue` 中的样式：

### 代码变更

**1. 遮罩层使用透明背景（用户要求恢复）：**

**修改前：**
```css
.group-form-overlay {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  background: rgba(0, 0, 0, 0.5); /* 半透明黑色遮罩，遮挡底层内容 */
  display: flex;
  align-items: center;
  justify-content: center;
  z-index: 1000;
  animation: fadeIn 0.2s ease-out;
}
```

**修改后：**
```css
.group-form-overlay {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  background: transparent; /* 透明遮罩 */
  display: flex;
  align-items: center;
  justify-content: center;
  z-index: 1000;
  animation: fadeIn 0.2s ease-out;
}
```

**2. 表单容器使用明确的不透明背景色（关键修复）：**

**问题原因：** `var(--bg-secondary)` CSS 变量计算后为 `rgba(0, 0, 0, 0)`（完全透明）

**修改前：**
```css
.group-form {
  position: relative;
  width: 420px;
  background: var(--bg-secondary);
  border-radius: 16px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.3);
  opacity: 1; /* 弹出框透明度，避免过于透明导致看不清 */
  overflow: hidden;
  animation: slideUp 0.3s ease-out;
}
```

**修改后：**
```css
.group-form {
  position: relative;
  width: 420px;
  background: #2d2d30; /* 使用明确的不透明背景色，避免 CSS 变量计算为透明 */
  border-radius: 16px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.3);
  opacity: 1; /* 弹出框不透明 */
  overflow: hidden;
  animation: slideUp 0.3s ease-out;
}
```

**3. 装饰性背景圆圈设置为不透明：**

**修改前：**
```css
.decoration-circle {
  position: absolute;
  border-radius: 50%;
  opacity: 0.05;
}
```

**修改后：**
```css
.decoration-circle {
  position: absolute;
  border-radius: 50%;
  opacity: 1; /* 装饰性背景圆圈透明度设置为 1 */
}
```

**4. 表单主体设置为不透明：**


**修改后：**
```css

}
```

