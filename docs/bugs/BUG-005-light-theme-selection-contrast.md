# BUG-005: 浅色主题下终端选中文字对比度不足

## 问题描述

**发现日期**: 2026-04-02

**严重程度**: 中

**影响范围**: 终端显示 - 浅色主题

**问题描述**: 
在浅色主题下，终端中选中的文字与背景对比度不足，导致用户难以看清选中的内容。这严重影响了用户体验，特别是在需要复制终端内容的场景下。

## 复现步骤

1. 启动应用程序
2. 进入设置页面 -> 外观设置
3. 切换到浅色主题
4. 连接到一个SSH会话
5. 在终端中尝试选中文字
6. 观察选中文字的显示效果

## 预期行为

在浅色主题下，选中的文字应该有明显的背景色和文字颜色对比，确保用户能够清楚地看到选中的内容。

## 实际行为

- 深色主题：选中文字对比度良好 ✓
- 浅色主题：选中文字对比度不足，难以辨认 ✗

## 根本原因分析

在浅色主题下，终端的选中背景色和文字颜色设置不当，导致对比度不足。需要为浅色主题设置合适的选中样式。

xterm.js 的选中样式通过 CSS 类 `.xterm-selection` 控制，需要根据当前主题动态调整选中背景色。

## 影响的文件

- `src/renderer/src/components/terminal/XTerminal.vue` - 终端组件
- `src/renderer/src/stores/settings.ts` - 设置状态管理

## 解决方案

### 方案 1: 通过 CSS 变量动态设置选中样式

在终端组件中添加 CSS 样式，根据当前主题设置选中背景色：

```css
/* 浅色主题下的选中样式 */
.light .x-terminal :deep(.xterm-selection) {
  background-color: rgba(0, 120, 215, 0.3) !important;
}

/* 深色主题下的选中样式 */
.dark .x-terminal :deep(.xterm-selection) {
  background-color: rgba(255, 255, 255, 0.3) !important;
}
```

**最终实现**：
- 深色主题：使用 xterm.js 默认选中样式
- 浅色主题：通过 CSS 强制设置装饰元素背景色

**修复方法**：
1. 在 `XTerminal.vue` 中添加 CSS 样式，使用 `[data-theme="light"]` 属性选择器只在浅色主题下生效
2. 使用 `:deep()` 穿透作用域，强制设置 `.xterm-decoration-top` 的背景色
3. 使用 `!important` 确保优先级最高，覆盖 xterm.js 的默认样式

**代码实现**：
```css
/* 浅色主题下的终端装饰元素样式 - 用于显示选中效果 */
[data-theme="light"] .x-terminal :deep(.xterm-decoration-top) {
  background-color: var(--selection-bg, rgba(55, 58, 56, 0.322)) !important;
}
```

**调整历史**：
1. 初始尝试：`#add6ff`（浅蓝色不透明）- 在白色背景上不够明显
2. 方案2：`rgba(0, 120, 215, 0.5)`（蓝色半透明，透明度50%）- 在白色背景上明显但还不够
3. 方案3：`rgba(0, 120, 215, 1)`（蓝色不透明，完全不透明）- 通过 theme 配置，但未生效
4. 方案4：通过 CSS 变量强制设置装饰元素背景色 - 成功解决
5. 最终方案：使用 `[data-theme="light"]` 属性选择器，只在浅色主题下生效

**关键发现**：
- xterm.js 使用 `.xterm-decoration-top` 装饰元素来显示选中效果，而不是通过 `theme.selection` 配置
- 需要使用 `:deep()` 穿透 Vue 组件的作用域样式
- 需要使用 `!important` 确保样式优先级最高
- 使用 `[data-theme="light"]` 属性选择器可以让样式只在特定主题下生效
