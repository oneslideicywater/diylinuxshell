# BUG-002: 右键菜单添加会话后菜单项不消失

## 问题描述

右击子分组，弹出菜单项，选择"添加会话"后，弹出编辑框，但右键菜单项没有消失，仍然显示在界面上。

## 问题原因

`handleNewSessionFromMenu` 函数只关闭了部分菜单状态（`sessionContextMenuVisible` 和 `showGroupSubmenu`），但没有关闭 `groupContextMenuVisible`。当右击子分组时，需要关闭的是所有右键菜单。

## 复现步骤

1. 启动应用
2. 右击任意分组（包括默认分组或子分组）
3. 在弹出的右键菜单中选择"添加会话"
4. 观察右键菜单是否消失

**预期结果**: 右键菜单应该立即消失，只显示编辑表单
**实际结果**: 右键菜单仍然显示在界面上

## 修复方案

修改 `src/renderer/src/components/session/SessionList.vue` 中的 `handleNewSessionFromMenu` 函数：

### 代码变更

**修改前：**
```typescript
const handleNewSessionFromMenu = () => {
  sessionContextMenuVisible.value = false
  showGroupSubmenu.value = false
  
  // 传递当前右键点击的分组 ID，如果未指定则传到默认分组
  emit('add-session', currentRightClickGroupId.value)
  currentRightClickGroupId.value = undefined
}
```

**修改后：**
```typescript
const handleNewSessionFromMenu = () => {
  // 关闭所有右键菜单
  closeAllContextMenus()
  
  // 传递当前右键点击的分组 ID，如果未指定则传到默认分组
  emit('add-session', currentRightClickGroupId.value)
  currentRightClickGroupId.value = undefined
}
```

## 验证方法

### 手动验证
1. 启动应用：`npm run dev`
2. 右击任意分组
3. 选择"添加会话"菜单项
4. 验证右键菜单已消失，只显示编辑表单

### 代码验证
修复后，`handleNewSessionFromMenu` 函数调用 `closeAllContextMenus()` 函数，该函数会关闭所有右键菜单状态：
- `sessionContextMenuVisible`
- `groupContextMenuVisible`
- `showGroupSubmenu`
