# BUG-002-子分组缩进过大导致超出侧边栏

## Bug 信息

- **编号**: BUG-002
- **标题**: 子分组缩进过大导致超出侧边栏
- **严重程度**: 中
- **状态**: 已修复
- **发现日期**: 2026-04-03
- **修复日期**: 2026-04-03

## 问题描述

### 复现步骤

1. 启动应用
2. 创建一个根分组
3. 在根分组下创建子分组（第 2 层）
4. 继续在子分组下创建子分组（第 3-5 层）
5. 观察第 4、5 层分组的显示情况

### 预期行为

- 所有层级的分组都应该在侧边栏内正常显示
- 分组名称应该有足够宽度显示内容
- 第 5 层分组不应该超出侧边栏右边界

### 实际行为

- 子分组缩进过大（每层约 32px）
- 嵌套层级达到 4-5 层时，子分组几乎完全被挤出可视区域
- 分组名称宽度不足，无法显示完整内容

## 原因分析

### 根本原因

缩进计算存在**重复累加**问题，导致每层缩进值过大：

1. **动态内边距**: `paddingLeft: ${(subGroup.depth - 1) * 8}px` (8px/层)
2. **容器内边距**: `.sub-groups { padding-left: 8px }` (8px/层)
3. **额外边距**: `.session-group.sub-group { margin-left: 16px }` (16px/层) ❌

**总计**: 32px/层 × 5 层 = **160px** 缩进

### 代码位置

- `src/renderer/src/components/session/SessionGroupTree.vue:273-276`
- `src/renderer/src/components/session/SessionGroupTree.vue:265-271`

## 解决方案

### 修复内容

移除重复的 `margin-left`，仅使用 `paddingLeft` 控制缩进：

#### SessionGroupTree.vue

**修复前**:
```css
.session-group.sub-group {
  margin-left: 16px;  /* ❌ 额外的 16px */
  position: relative;
}

.session-group.sub-group::before {
  left: -12px;  /* 连接线位置 */
}
```

**修复后**:
```css
.session-group.sub-group {
  /* 移除 margin-left，仅使用 paddingLeft 控制缩进 */
  position: relative;
}

.session-group.sub-group::before {
  left: -8px;  /* 调整连接线位置以匹配新缩进 */
}
```

#### SessionList.vue

**修复后**:
```css
.sub-groups {
  padding-left: 8px;  /* 每层 8px 缩进 */
  border-left: 1px solid var(--border-color-light);
  margin-left: 4px;
}

.group-sessions {
  padding-left: 12px;  /* 会话项缩进 */
}
```

### 修复效果

**第一次修复**: 
- 修复前：32px/层 × 5 层 = 160px 缩进
- 修复后：8px/层 × 5 层 = 40px 缩进

**用户反馈问题依然存在**：
- 实际每层缩进仍为 12px（因为 `.sub-groups` 有 `padding-left: 8px` + `margin-left: 4px`）
- 总计：12px/层 × 5 层 = 60px，加上分组头部 padding，仍然过大

**第二次修复（最终）**:
- 完全移除 `.sub-groups` 的 `padding-left` 和 `margin-left`
- 仅保留动态 `paddingLeft: ${(subGroup.depth - 1) * 8}px`
- **最终效果**：8px/层 × 5 层 = 40px 缩进

**新增功能**：
- 侧边栏添加 `overflow-x: hidden` 和 `min-width: 0` 防止内容溢出
- 保持 `overflow-y: auto` 支持垂直滚动
