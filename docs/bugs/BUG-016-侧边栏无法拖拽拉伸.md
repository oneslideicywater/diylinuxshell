# BUG-016-侧边栏无法拖拽拉伸.md

## Bug 信息

- **编号**: BUG-016
- **标题**: 侧边栏无法拖拽拉伸
- **发现时间**: 2026-04-03
- **发现阶段**: 功能实现后测试
- **严重程度**: 高
- **状态**: ✅ 已修复

## 复现步骤

1. 启动应用
2. 鼠标移动到会话侧边栏右边界
3. 光标变为 ↔ 形状
4. 按住鼠标左键拖拽
5. **实际结果**: 侧边栏宽度不随鼠标移动变化
6. **预期结果**: 侧边栏宽度应该跟随鼠标拖拽实时变化

## 问题现象

- 拖拽手柄显示正常
- 鼠标悬停效果正常
- 拖拽时光标变化正常
- 但侧边栏宽度不响应拖拽操作

## 根本原因

经过深入分析，发现最初实现的位置错误：

### 问题：拖拽功能实现位置错误

**错误实现**：
- 最初在 `SessionList.vue` 组件中实现了拖拽功能
- 调整的是 `.session-list` 的宽度，而不是整个侧边栏 `.app-sidebar` 的宽度
- 导致拖拽范围受限，无法真正调整整个侧边栏的宽度

**正确实现**：
- 应该在 `AppLayout.vue` 布局组件中实现拖拽功能
- 直接调整 `.app-sidebar` 的宽度
- 拖拽手柄应该位于侧边栏和主内容区之间

## 解决方案

### 1. 在 AppLayout.vue 中实现拖拽功能

**模板结构**：
```vue
<div class="app-body">
  <!-- 左侧边栏 -->
  <aside 
    class="app-sidebar" 
    :style="{ width: `${sidebarWidth}px` }"
  >
    <Sidebar />
  </aside>

  <!-- 拖拽调整手柄 -->
  <div
    class="sidebar-resize-handle"
    :class="{ 'resizing': isResizing }"
    @mousedown="handleResizeStart"
    title="拖拽调整侧边栏宽度"
  >
    <div class="resize-line"></div>
  </div>

  <!-- 主内容区 -->
  <main class="app-main">
    <!-- ... -->
  </main>
</div>
```

**脚本逻辑**：
```typescript
// 侧边栏宽度相关
const SIDEBAR_MIN_WIDTH = 200
const SIDEBAR_MAX_WIDTH = 500
const SIDEBAR_DEFAULT_WIDTH = 240
const SIDEBAR_WIDTH_STORAGE_KEY = 'app-sidebar-width'

const sidebarWidth = ref(SIDEBAR_DEFAULT_WIDTH)
const isResizing = ref(false)

/**
 * 从 localStorage 加载侧边栏宽度
 */
const loadSidebarWidth = () => {
  try {
    const stored = localStorage.getItem(SIDEBAR_WIDTH_STORAGE_KEY)
    if (stored) {
      const width = parseInt(stored, 10)
      if (width >= SIDEBAR_MIN_WIDTH && width <= SIDEBAR_MAX_WIDTH) {
        sidebarWidth.value = width
      }
    }
  } catch (error) {
    console.error('Failed to load sidebar width:', error)
  }
}

/**
 * 保存侧边栏宽度到 localStorage
 */
const saveSidebarWidth = () => {
  try {
    localStorage.setItem(SIDEBAR_WIDTH_STORAGE_KEY, sidebarWidth.value.toString())
  } catch (error) {
    console.error('Failed to save sidebar width:', error)
  }
}

/**
 * 开始调整侧边栏宽度（带调试日志）
 */
const handleResizeStart = (e: MouseEvent) => {
  console.log('[AppLayout] sidebar mousedown 事件触发', {
    clientX: e.clientX,
    button: e.button
  })
  
  // 阻止默认行为和事件冒泡
  e.preventDefault()
  e.stopPropagation()
  
  isResizing.value = true
  document.body.style.cursor = 'ew-resize'
  document.body.style.userSelect = 'none'
  
  const startX = e.clientX
  const startWidth = sidebarWidth.value
  
  console.log('[AppLayout] 初始状态', { startX, startWidth })
  
  // 使用闭包保存状态
  const onMouseMove = (moveEvent: MouseEvent) => {
    const delta = moveEvent.clientX - startX
    let newWidth = startWidth + delta
    
    // 限制宽度范围
    newWidth = Math.max(SIDEBAR_MIN_WIDTH, Math.min(SIDEBAR_MAX_WIDTH, newWidth))
    sidebarWidth.value = newWidth
    
    console.log('[AppLayout] mousemove', {
      clientX: moveEvent.clientX,
      delta,
      newWidth
    })
  }
  
  const onMouseUp = () => {
    console.log('[AppLayout] mouseup 事件触发')
    
    isResizing.value = false
    document.body.style.cursor = ''
    document.body.style.userSelect = ''
    saveSidebarWidth()
    document.removeEventListener('mousemove', onMouseMove)
    document.removeEventListener('mouseup', onMouseUp)
  }
  
  // 立即添加事件监听器
  document.addEventListener('mousemove', onMouseMove)
  document.addEventListener('mouseup', onMouseUp)
  
  console.log('[AppLayout] 事件监听器已添加')
}
```

## 经验教训

1. **正确的组件层级**：拖拽功能应该实现在布局组件中，而不是子组件中
2. **调试日志**：保留调试日志有助于排查问题
3. **事件处理**：使用闭包保存状态，确保事件监听器正确绑定和解绑
4. **用户持久化**：使用 localStorage 保存用户偏好设置
