# BUG-004: 竖线光标不闪烁

## 问题描述

**发现日期**: 2026-04-01

**严重程度**: 低

**影响范围**: 终端光标显示

**问题描述**: 
当光标样式设置为竖线（bar）时，光标不会闪烁。而块状（block）和下划线（underline）光标都可以正常闪烁。

## 复现步骤

1. 启动应用程序
2. 连接到一个SSH会话
3. 进入设置页面 -> 终端设置
4. 将光标样式设置为"竖线"
5. 确保光标闪烁开关已开启
6. 观察终端中的光标

## 预期行为

当光标闪烁开关开启时，所有光标样式（块状、下划线、竖线）都应该闪烁。

## 实际行为

- 块状光标：闪烁 ✓
- 下划线光标：闪烁 ✓
- 竖线光标：不闪烁 ✗

## 根本原因分析

这是 xterm.js 的已知行为。在 xterm.js 中，竖线光标（bar cursor）默认不闪烁，即使设置了 `cursorBlink: true`。

这是因为 xterm.js 的实现中，竖线光标的闪烁效果在某些情况下可能导致视觉问题，因此默认禁用了竖线光标的闪烁。

## 影响的文件

- `src/renderer/src/components/terminal/XTerminal.vue` - 终端组件

## 解决方案

### 方案 1: 接受当前行为（推荐）

这是 xterm.js 的设计决策，不是 bug。可以在设置页面添加说明，告知用户竖线光标不支持闪烁。

### 方案 2: 使用 CSS 动画模拟闪烁

可以通过 CSS 动画来模拟竖线光标的闪烁效果：

```css
/* 在 XTerminal.vue 中添加 */
.x-terminal :deep(.xterm-cursor-bar) {
  animation: cursor-blink-bar 1s step-end infinite;
}

@keyframes cursor-blink-bar {
  0%, 50% { opacity: 1; }
  51%, 100% { opacity: 0; }
}
```

### 方案 3: 在设置页面添加提示

在光标样式选择器旁边添加提示信息，说明竖线光标不支持闪烁。
