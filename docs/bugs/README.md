# Bugs 文档索引

按功能模块分类的所有 Bug 文档。

## 目录结构

```
bugs/
├── connection/        # 连接相关 Bug
├── context-menu/      # 右键菜单相关 Bug
├── session/           # 会话管理相关 Bug（分组、会话表单等）
├── sftp/              # SFTP 相关 Bug
│   ├── delete/       # SFTP 删除功能
│   ├── ui/           # SFTP UI 问题
│   └── upload/       # SFTP 上传功能
├── tab/               # 标签页管理相关 Bug
├── terminal/          # 终端核心功能 Bug（光标、PTY、vim 等）
├── theme/             # 主题相关 Bug（浅色/深色主题）
└── ui/                # 其他 UI 问题（窗口拖动、对话框等）
```
