## 2. 产品概述

### 2.1 产品背景

在日常开发和运维工作中，开发人员经常需要连接和管理多台Linux服务器。市面上已有的终端管理工具（如XShell、SecureCRT、PuTTY等）虽然功能强大，但存在以下问题：

- 商业软件收费昂贵，免费版本功能受限
- 部分工具仅支持Windows平台
- 界面老旧，用户体验不佳
- 自定义能力有限，无法满足个性化需求

因此，我们决定开发一款**免费、开源、跨平台**的终端管理工具，提供现代化的用户界面和丰富的功能。

### 2.2 产品定位

一款面向开发人员和运维工程师的**轻量级、现代化终端管理工具**，支持SSH协议连接，提供会话管理、多标签页、命令片段等核心功能。

### 2.3 目标用户

| 用户群体 | 特征描述 |
|----------|----------|
| 后端开发工程师 | 需要频繁连接测试/生产服务器，执行部署、日志查看等操作 |
| 运维工程师 | 需要管理大量服务器，执行批量操作 |
| DevOps工程师 | 需要在不同环境间切换，执行自动化脚本 |
| 学生/学习者 | 学习Linux系统管理，需要免费的SSH工具 |

##### 3.2.4.2 会话分组功能详细说明

**功能描述**：支持将会话按项目、环境或其他维度进行分组管理，提高会话组织效率。

**功能列表**：

| 功能项 | 描述 | 优先级 |
|--------|------|--------|
| 创建分组 | 右键点击会话列表空白区域（包括空状态），选择"新建分组"创建新分组 | P1 |
| 编辑分组 | 右键点击分组头部，选择"编辑分组"修改分组名称和图标 | P1 |
| 删除分组 | 右键点击分组头部，选择"删除分组"删除分组，分组内会话移至未分组 | P1 |
| 分组展开/折叠 | 点击分组头部展开或折叠分组内容 | P1 |
| 会话移动到分组 | 右键点击会话项，选择"移动到分组"，在子菜单中选择目标分组 | P1 |
| 批量会话归组 | 支持选中多个会话，批量移动到指定分组 | P2 |
| 拖拽会话入组 | 拖拽会话项到分组头部或分组内，实现快速归组 | P2 |
| 分组图标选择 | 创建或编辑分组时，可选择不同的图标标识分组 | P2 |
| 分组会话计数 | 分组头部显示该分组下的会话数量 | P2 |
| 未分组会话 | 支持显示未分组会话列表 | P1 |

**交互设计**：

1. **右键菜单层级**：
   - 会话列表空白区域右键（包括空状态和有会话时的空白区域） → 显示"新建分组"菜单
   - 分组头部右键 → 显示"添加会话到此分组"、"编辑分组"、"删除分组"、"新建子分组"菜单
   - 会话项右键 → 显示"移动到分组"菜单（带子菜单）

2. **分组表单**：
   - 分组名称输入框（必填）
   - 图标选择器（可选，默认文件夹图标）
   - 取消/创建按钮

3. **分组图标**：
   - 文件夹图标（默认）
   - 服务器图标
   - 云图标
   - 数据库图标
   - 代码图标
   - 星标图标

4. **拖拽交互**：
   - 拖拽会话项到分组头部：高亮显示目标分组
   - 拖拽会话项到分组内会话之间：显示插入位置指示线
   - 拖拽分组到另一个分组：创建子分组关系（受层级限制）
   - 松开鼠标完成归组或创建嵌套

5. **批量操作**：
   - 按住 Ctrl/Cmd 多选会话
   - 右键选择"移动到分组"
   - 选择目标分组后批量移动

6. **嵌套层级限制**：
   - 创建子分组时检查当前层级，达到5级上限时禁止创建并弹出提示
   - 拖拽分组时检查目标位置的层级，超出限制时禁止移入并弹出提示
   - 提示文案明确说明层级上限和当前状态

**数据结构**：

```typescript
interface SessionGroup {
  id: string
  name: string
  icon?: string
  expanded?: boolean  // 展开/折叠状态
  createdAt: Date
  updatedAt: Date
}

interface Session {
  id: string
  name: string
  host: string
  port: number
  username: string
  groupId?: string  // 所属分组ID，undefined 表示未分组
  // ... 其他字段
}
```

**界面样式**：

1. **树形面板展示**：
   - 左侧会话侧边栏采用树形结构
   - 分组为父节点，会话为子节点
   - **支持多级嵌套，最多5级层级**
   - 子分组相对父分组缩进显示，层级关系清晰

2. **轻量化设计**：
   - 分组头部轻量化，仅显示图标、名称和会话数
   - 展开/折叠图标使用简洁的箭头（▶ 展开，▼ 折叠）
   - 悬停效果明显但不突兀
   - 无冗余操作，所有功能通过右键菜单或拖拽实现

3. **视觉反馈**：
   - 拖拽时目标分组高亮显示
   - 选中会话背景色变化
   - 删除分组时二次确认弹窗
   - 嵌套层级达到上限时，目标分组显示禁用状态

4. **嵌套层级提示**：
   - 创建子分组超限时，弹出提示对话框
   - 拖拽移入超限时，显示错误提示
   - 提示文案清晰明确，告知用户层级上限

**持久化**：分组信息保存在本地存储中，重启应用后保持分组结构。

**删除二次确认**：
- 删除含有会话的分组时，弹出确认对话框
- 提示文字："该分组包含 {count} 个会话，删除分组将会话移至未分组，确定继续？"
- 确认按钮：红色警告样式
- 取消按钮：默认样式

**嵌套层级限制**：
- 最大嵌套层级：5 级（根分组为第 1 级）
- 创建子分组时检查：当前分组层级 >= 5 时，禁止创建并提示
- 拖拽分组时检查：目标位置层级 >= 5 时，禁止移入并提示
- 提示文案：
  - 创建超限："子分组嵌套层级已达上限（最多 5 级），无法继续创建下级分组。"
  - 拖拽超限："目标位置嵌套层级超限，无法移入该子分组下。"
  - Tooltip 提示："支持多级子分组嵌套，最多 5 级层级，便于按项目/环境精细化管理会话。"

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 要求 |
|------|------|
| 启动时间 | 冷启动时间 < 3秒 |
| 连接建立 | SSH连接建立时间 < 2秒（网络正常情况下） |
| 终端响应 | 终端输入延迟 < 100ms |
| 内存占用 | 空闲状态内存占用 < 100MB |
| 并发连接 | 支持同时保持10个以上活跃连接 |

### 4.2 安全要求

| 要求 | 描述 |
|------|------|
| 密码加密 | 保存的密码必须使用加密存储 |
| 传输加密 | 所有SSH通信使用加密传输 |
| 密钥保护 | 私钥文件权限严格控制 |
| 会话隔离 | 不同会话之间相互隔离 |

### 4.3 兼容性要求

| 平台 | 支持情况 |
|------|----------|
| Windows | Windows 10 及以上版本 |
| macOS | macOS 10.15 及以上版本 |
| Linux | 主流发行版（Ubuntu、CentOS、Debian等） |

### 4.4 可维护性要求

- 代码结构清晰，模块化设计
- 提供完善的日志记录机制
- 支持配置文件的备份和恢复

## 8. 风险评估

| 风险项 | 风险描述 | 应对措施 |
|--------|----------|----------|
| SSH协议兼容性 | 不同服务器SSH版本差异 | 使用成熟的SSH库，做好兼容性测试 |
| 终端兼容性 | 不同终端类型转义序列差异 | 使用成熟的终端模拟组件 |
| 安全风险 | 密码存储、密钥管理安全 | 使用系统级加密API，参考业界最佳实践 |
| 跨平台问题 | 不同操作系统适配问题 | 使用跨平台技术栈，充分测试 |
